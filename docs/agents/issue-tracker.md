# Issue tracker: GitHub

Issues and specs for this repo live as GitHub Issues. Use the `gh` CLI for all operations.

## Conventions

- Create issues with `gh issue create`.
- Read issues with `gh issue view <number> --comments`.
- Apply labels with `gh issue edit <number> --add-label`.
- PRs are not a triage request surface.
- Use GitHub issue dependencies when available. If dependencies are unavailable, keep a `Blocked by` line in each ticket body.
